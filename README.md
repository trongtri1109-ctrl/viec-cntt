# Việc CNTT – Ricons

Bản giao diện mẫu (prototype) quản lý công việc & báo cáo tuần Phòng CNTT Ricons.

**Xem trực tiếp:** https://dolamthien.github.io/viec-cntt/

- Một file `index.html`, mở bằng trình duyệt là chạy, không cần máy chủ.
- Dữ liệu chỉ là bản mẫu, lưu trên trình duyệt: tải lại trang thì dữ liệu nhập thử sẽ mất.
- Đổi vai (TP / thành viên) ở góc trái để xem theo từng người.
